# Zhiné Brand Guide

> Version 0.1  
> Practical brand usage guide for Zhiné open-source materials.

## 1. Purpose

This document translates the Zhiné Global Brand Charter into practical usage guidance for README files, documentation, repository descriptions, presentations, websites, community materials, and release notes.

It does not replace the Brand Charter. It provides operating rules for consistent expression.

---

## 2. Master Brand

| Item | Usage |
|---|---|
| Display name | **Zhiné** |
| Digital name | **zhine** |
| GitHub organization | **zhine-ai** |
| Main repository | **zhine** |
| Suggested package name | **ai.zhine.app** |
| Official domain | **zhine.ai** |

Use **Zhiné** in human-facing brand contexts.  
Use **zhine** in code, repositories, packages, folders, commands, and file names.

---

## 3. Core Lines

These four lines are fixed brand anchors.

### Slogan

> **不止于懂你。**  
> **Beyond understanding.**

### Mission Line

> **超越，才是自己。**  
> **To transcend is to become oneself.**

### Brand Belief

> **人工智能的真正意义，不是让机器更像人，而是让人突破自己。**  
> **The true meaning of artificial intelligence is not to make machines more human, but to help humans transcend their own limits.**

### AI Ethics Line

> **AI 应成为人类共享的能力，而不是少数人的特权。**  
> **AI should be a shared human capability, not a privilege of the few.**

Do not rewrite these lines casually. For formal materials, keep them exact.

## 4. Positioning Language

### Standard Definition

Use this when a concise project definition is needed:

```text
Zhiné is an open-source project for building a Personal Intelligence Companion on top of an open and evolvable cognitive architecture.
```

Chinese version:

```text
Zhiné 是一个开源项目，旨在基于开放、可演进认知架构，构建个人智慧伙伴。
```

### Technical Definition

```text
At the technical level, Zhiné is built around the Personal Cognitive Model: a governable personal cognitive asset system composed of memory, knowledge, experience, skills, strategies, benchmarks, adapters, and evolution logs.
```

Chinese version:

```text
在技术层，Zhiné 以个人认知模型为核心。个人认知模型是由记忆、知识、经验、技能、策略、评测、适配层和演进日志共同构成的可治理个人认知资产系统。
```

## 5. Term Hierarchy

| Layer | Preferred Term |
|---|---|
| Brand category | 个人智慧伙伴 / Personal Intelligence Companion |
| Technical core | 个人认知模型 / Personal Cognitive Model |
| Architecture thesis | 开放认知架构 / Open Cognitive Architecture |
| User-facing asset | 个人智慧资产 / Personal Intelligence Assets |
| Ethical foundation | 普惠智能 / Inclusive AI |

Brand speaks of intelligence. Technology speaks of cognition. User experience speaks of being understood over time, thinking together, and turning personal knowledge, experience, and methods into long-term intelligence assets.

---

## 6. Voice

Zhiné should sound like an experienced thinker.

Preferred qualities:

- calm;
- clear;
- honest;
- restrained;
- reliable;
- technically credible;
- humanly aware;
- globally oriented.

Avoid:

- hype;
- exaggerated claims;
- anxiety-driven marketing;
- false certainty;
- manipulative language;
- emotional dependency language;
- mystical claims about consciousness or digital souls.

---

## 7. What Zhiné Is Not

Do not describe Zhiné as:

- another chatbot;
- a generic agent framework;
- a local RAG demo;
- a cloud model wrapper;
- a digital soul project;
- a personality-copying project;
- an unconstrained self-evolving system;
- a premium AI privilege system for a small group.

Correct framing:

```text
Zhiné is a personal cognitive infrastructure for long-term personal intelligence assets.
```

## 10. Naming Rules

Recommended repository names:

| Repository | Purpose |
|---|---|
| `zhine` | Main monorepo |
| `zhine-docs` | Documentation if separated later |
| `zhine-specs` | Formal specifications if separated later |
| `zhine-core` | Core runtime if separated later |
| `zhine-memory` | Memory engine if separated later |
| `zhine-evals` | Benchmark and evaluation tools if separated later |

Initial recommendation: use a monorepo until architecture and specifications are stable.

---

## 11. Brand Boundaries

Zhiné brand materials must not imply:

- AI replaces human judgment;
- Zhiné owns user memory;
- remote models are the default owner of personal assets;
- personal data is open because the project is open source;
- self-training can proceed without permission and evaluation;
- Zhiné copies consciousness, personality, or identity;
- high-quality AI should be restricted to premium users only.

---

## 12. Summary

Use Zhiné with restraint and clarity.

The brand should carry:

```text
international perspective
technical credibility
human depth
open spirit
```

The central message remains:

```text
Zhiné helps each person own, govern, and grow their personal intelligence.
```
