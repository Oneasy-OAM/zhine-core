# Zhiné Open Project Docs v0.1

This package contains the first open-source project documentation set for Zhiné.

It is based on:

- Zhiné Global Brand Charter v0.3
- Zhiné Technical Whitepaper v0.3
- Zhiné README v0.1

## Files

| File | Purpose |
|---|---|
| `README.md` | GitHub entry document |
| `docs/architecture.md` | Conceptual architecture, layers, module boundaries, flows, and acceptance criteria |
| `docs/principles.md` | Engineering principles, ethical constraints, and non-negotiable rules |
| `docs/roadmap.md` | Phased roadmap from project definition to ecosystem |
| `docs/governance.md` | Initial open-source governance model |
| `docs/ai-ethics.md` | Inclusive AI, fairness, accessibility, human sovereignty, and responsible growth |

| `SECURITY.md` | Security policy and vulnerability reporting guidance |
| `LICENSE` | Apache License 2.0 text for code baseline |

## Core Direction

Zhiné is an open-source project for building a Personal Intelligence Companion on top of an open and evolvable cognitive architecture.

Core anchors:

```text
Personal Intelligence Companion / 个人智慧伙伴
Personal Cognitive Model / 个人认知模型
Open Cognitive Architecture / 开放认知架构
Inclusive AI / 普惠智能
```
